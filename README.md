# 🌐 Vedant Mishra — Official Cloud & DevOps Portfolio

Live URL: **[https://vedantoncloud.github.io](https://vedantoncloud.github.io)**

High-performance, modern, and interactive portfolio website built for **Vedant Mishra** (Cloud Architect, DevOps & Platform Engineer).

---

## ⚡ Key Highlights & Architecture

- **Glassmorphism Cyber Theme**: Built with custom Tailwind CSS, Plus Jakarta Sans, and Fira Code monospace accents.
- **Interactive Particle Constellation**: Zero-dependency HTML5 Canvas rendering ambient cosmic constellations that react to window sizes.
- **Interactive Terminal Shell**: Interactive zsh/bash emulator in the hero section where visitors can type `help`, `skills`, `projects`, `certs`, `exp`, `contact`, and `sudo`.
- **Dynamic Typing Subtitle**: Fluid role cycler highlighting AWS serverless, OCI, Docker, CloudForge, and CI/CD pipelines.
- **Dynamic Category Filter**: 1-click filtering across Platform/PaaS, DevOps & CI/CD, and Cloud/FinOps.
- **Direct Web Gmail Launcher**: Instant email dispatch with pre-filled subject and body without needing desktop mail client setup.
- **Live GitHub Metrics**: Real-time stats, streak tracker with Indian timezone (`Asia/Kolkata`), and verified certification badges.

## 🚀 How to Launch on GitHub Pages (100% Free Forever)

### Step 1: Create the GitHub Repository
1. Go to [https://github.com/new](https://github.com/new).
2. Set the **Repository name** to: `vedantoncloud.github.io`  
   *(Notice: Naming it `<username>.github.io` activates GitHub's special personal website hosting automatically!).*
3. Make sure it is set to **Public**.
4. Click **Create repository**.

---

### Step 2: Push the Portfolio Code
Open PowerShell or your terminal in this directory:
`C:\Users\vedan\.gemini\antigravity\scratch\vedantoncloud.github.io`

Run the following commands:

```bash
git init
git branch -M main
git add .
git commit -m "feat: launch world-class cloud & devops portfolio website"
git remote add origin https://github.com/vedantoncloud/vedantoncloud.github.io.git
git push -u origin main
```

*(If you already created the repository with a default README, run `git push -u origin main --force`).*

---

### Step 3: Enable GitHub Pages (Usually Automatic)
1. Go to your repository settings: `https://github.com/vedantoncloud/vedantoncloud.github.io/settings/pages`.
2. Under **Build and deployment** > **Source**, verify it is set to **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be live at:  
   👉 **https://vedantoncloud.github.io**
